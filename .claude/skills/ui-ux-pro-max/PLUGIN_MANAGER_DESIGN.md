# 插件管理页面 - UI/UX 重构设计文档

## 📋 设计概述

基于 **Data-Dense Dashboard** 设计风格，为插件管理页面进行了全面的 UI/UX 改进，重点解决**已加载/未加载插件**的清晰区分问题。

---

## 🎨 设计系统

### 视觉风格
- **风格**: Data-Dense Dashboard（数据密集型仪表板）
- **主色调**: #7C3AED（紫色）- 激发活力与专业性
- **辅助色**: #F97316（橙色）- 强调行动按钮
- **背景**: #FAF5FF（浅紫）- 保持一致性

## 🎨 设计原则应用

### 1. **视觉层次**
```
统计仪表板 (重要) > 筛选栏 (次要) > 插件列表 (内容)
```

### 2. **一致性**
- 所有卡片使用相同的圆角 (12px)
- 统一的阴影深度 (0 1px 3px → 0 8px 16px)
- 一致的间距系统 (4px 基础单位)

### 3. **反馈**
- 悬停 → 阴影加深 + 边框高亮
- 加载 → 按钮禁用 + 旋转图标
- 成功 → 绿色日志 + 成功消息

## 🔧 技术实现

### 关键代码片段

#### 1. 统计计算
```javascript
const runningPlugins = computed(() => {
  return loadedPlugins.value.filter(p => p.status === 'ACTIVE').length
})
```

#### 2. 过滤逻辑
```javascript
const filteredLoadedPlugins = computed(() => {
  let plugins = [...loadedPlugins.value]

  // 搜索过滤
  if (searchQuery.value.trim()) {
    const term = searchQuery.value.toLowerCase()
    plugins = plugins.filter(p =>
      (p.name || '').toLowerCase().includes(term) ||
      (p.pluginId || '').toLowerCase().includes(term)
    )
  }

  // 类型过滤
  if (filterType.value) {
    plugins = plugins.filter(p => (p.type || 'DATABASE') === filterType.value)
  }

  return plugins
})
```

#### 3. 状态样式映射
```javascript
const getStatusClass = (status) => {
  if (status === 'ACTIVE') return 'running'
  if (status === 'ERROR') return 'error'
  return 'loaded'
}
```
